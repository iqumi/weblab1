# Лабораторная работа №1 — Страница-визитка

Одностраничный адаптивный сайт-портфолио, сверстанный на чистом HTML/CSS
(Flexbox + Grid) без использования фреймворков.

**Автор:** Иван Иванов
**Группа:** ИТ-21

## Деплой
Ссылка на сайт: _добавьте после деплоя на GitHub Pages / Netlify / Vercel_

## Структура проекта
```
lab1-portfolio/
├─ index.html
├─ css/
│  └─ styles.css
├─ images/
│  └─ project1.svg ... project6.svg
├─ README.md
└─ .gitignore
```

## Реализованные секции
- Header с логотипом и навигацией (бургер-меню на мобильных)
- About / О себе
- Skills / Навыки — карточки с процентами
- Portfolio / Примеры работ — 6 карточек
- Contacts / Контакты
- Footer

## Адаптивность
Реализованы три брейкпоинта:
- Mobile ≤ 767px
- Tablet 768px–1023px
- Desktop ≥ 1024px

## Как открыть локально
Просто откройте `index.html` в браузере — внешние зависимости не требуются.
